SONORA PLAYER - DEBIAN INSTALLATION
====================================

You need an internet connection to build the app and search/download YouTube
content. Download only content you own or are authorized to save. Respect
YouTube's terms and creators' rights.

1. Install system prerequisites

Open a terminal and run:

    sudo apt update
    sudo apt install -y python3 python3-venv python3-tk ffmpeg

The build needs ffmpeg, ffplay, and ffprobe. Check that all three commands are
available:

    ffmpeg -version
    ffplay -version
    ffprobe -version

2. Build Sonora

Extract the SonoraPlayer_PyInstaller_SCROLL source folder, then open a terminal
in that folder (the folder containing app.py and build_pyinstaller.sh). Run:

    chmod +x build_pyinstaller.sh
    ./build_pyinstaller.sh

The build script creates .venv-build and installs PyInstaller and yt-dlp in
that isolated environment. It bundles yt-dlp and the FFmpeg tools it finds; you
do not need to install yt-dlp system-wide.

3. Launch Sonora

    ./dist/SonoraPlayer/run-sonora.sh

The standalone application is in dist/SonoraPlayer/. The portable archive is
created at SonoraPlayer-linux-x86_64.tar.gz.

4. Run from source instead of building

From this folder, run:

    python3 -m venv .venv-source
    source .venv-source/bin/activate
    python -m pip install --upgrade pip
    python -m pip install -r requirements-build.txt
    python -m pip install --upgrade yt-dlp
    python app.py

To leave the virtual environment, press Ctrl+C to stop the app and run:

    deactivate

5. Update yt-dlp in an existing build environment

After building once, update yt-dlp and rebuild with:

    source .venv-build/bin/activate
    python -m pip install --upgrade yt-dlp
    deactivate
    ./build_pyinstaller.sh

Music search and downloads require internet. Local music playback works offline.
